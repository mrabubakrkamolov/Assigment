5 main problems and solutions

1 problem - Large image files

The images on the webpage were large and could increase the amount of data that the browser needed to download. So instead of using JPG or PNG, I converted the images to WebP format to reduce their file size.

BEFORE
AFTER
Before: 
<img src="movie-poster.jpg"
alt="Movie poster">
After: 
<img src="movie-poster.webp"
alt="Movie poster">
2 problem - Images were not lazy loaded

All images could be loaded immediately, even when they were outside the visible area. I added lazy loading so the browser loads images only when they are needed.

Before: 
<img src="movie-poster.webp"
alt="Movie poster">
After: 
<img src="movie-poster.webp"
alt="Movie poster"
loading="lazy">
3 problem - Render-blocking JavaScript

The main JavaScript file could block HTML parsing and delay the page from becoming usable. Since the script uses the DOM, I added the defer attribute.

BEFORE 
<script
src="app.js">
</script>
AFTER 
<script
defer
src="app.js">
</script>

With defer, the browser can parse the HTML first and execute the script after the document has been parsed.

4 problem - CSS was not minified

The CSS file contained unnecessary spaces, line breaks and formatting. I minified the CSS to reduce the file size and make it faster to download.

Before: 
body {
    margin: 0;
    padding: 20px;
    font-family: Arial, sans-serif;
}
After: 
body{margin:0;padding:20px;font-family:Arial,sans-serif}
5 problem - Images had no dimensions

The images did not have fixed width and height values. I added image dimensions so the browser can reserve the correct space before the images finish loading.

Before: 
<img src="movie-poster.webp"
alt="Movie poster">
After: 
<img
src="movie-poster.webp"
alt="Movie poster"
width="300"
height="450">

Reflection

The optimization that had the most impact on my website was image optimization. Large images can require a lot of data to be downloaded, so converting them to WebP reduced their file size.

Lazy loading also helped because images outside the initial viewport did not need to be loaded immediately. This reduced the amount of resources required during the initial page load.

The other changes also improved the website performance. Using defer prevented the main JavaScript from blocking HTML parsing, CSS minification reduced the stylesheet size, and adding image dimensions helped the browser reserve space for images.
