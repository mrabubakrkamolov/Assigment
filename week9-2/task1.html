Worst Performance Metric

The worst metric identified in the original audit was Cumulative Layout Shift (CLS).

Original CLS Value: 0.279

Cause:

Lighthouse identified unsized image elements as the main cause of layout shifts.

The browser did not reserve space for images before they loaded, causing page elements to move.

Optimizations Applied

1. JavaScript Loading

Added the defer attribute to the jQuery script to avoid blocking HTML parsing.

Before: 

<script src="jquery.min.js"></script>

After: 

<script src="jquery.min.js" defer></script>

2. Image Dimensions

Added explicit width and height attributes to all three images.

This allows the browser to reserve space before the images finish loading and helps reduce layout shifts. 

<img
  src="image.jpg"
  width="1200"
  height="800"
  alt="Example image"
>

3. Lazy Loading

Added loading="lazy" to the second and third images because they appear further down the page. 

<img
  src="image.jpg"
  loading="lazy"
  alt="Example image"
>

4. Performance Result

After applying the optimizations, the Lighthouse Performance score improved from 85 to 100.

The main improvement came from preventing layout shifts caused by images and improving how JavaScript and images load.
